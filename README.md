# Drone Radar UA 🇺🇦

Професійний напіввійськовий інструмент для моніторингу повітряного простору та OSINT-аналізу з пріоритетним фокусом на **Запоріжжя** та **Київ** (а також всю територію України). Додаток розраховує балістичні точки падіння з точністю до метра, оновлює телеметрию в реальному часі та має вбудоване API для підключення мікроконтролерів ESP32.

---

## 🛠 Архітектура та стек
- **Бэкенд:** Node.js, Express, WebSockets, Axios.
- **Фронтенд:** HTML5, Leaflet.js (темна тактична карта CartoDB Dark Matter), WebSocket стрім (30 FPS).
- **Залізо:** Готовий REST API для інтеграції з ESP32 / Arduino через Wi-Fi.
